## 2. 데이터 소스

### 2.1. 교통사고 데이터 (분자)

**도로교통공단 교통사고분석시스템 (TAAS)**

| 속성 | 값 |
|---|---|
| **출처** | 교통사고분석시스템 GIS 조회 https://taas.koroad.or.kr/gis |
| **공공데이터포털 등재** | 데이터셋 ID `15075668` (교통사고 GIS정보) |
| **이용허락** | 출처표시(CC BY) |
| **저작자** | 도로교통공단 |
| **데이터 형식** | Excel (.xlsx) — 연도별 다운로드 |

**수집 조건:**
- **도시**: 서울특별시
- **심각도**: **사망 + 중상** (사망만은 표본 부족 → 눈 사고 10년 14건으로 구별 지도 불가능)
- **기간**: 2014~2023 각 연도별 (총 10개 파일)
- **선택 방법**: 조건검색 → 목록보기 → 엑셀 다운로드

**데이터 스키마:**
- 발생년월 (YYYY-MM)
- 시군구 (자치구명, 예: "중구", "영등포구")
- 기상상태 (경찰 기록값: "맑음", "흐림", "비", "눈", "안개" 등)
- 사고유형, 사망·중상·경상·부상신고자수 등

> **주의**: 발생 시각(시 0~23)과 위경도는 **미포함**. 이로 인해 분석 단위가 자치구(시군구)로 확정됨. 사고 기상분류는 경찰 정성 기록값을 사용(ASOS 정량 관측과 출처 이원화).

**저장 위치:**
```
data/raw/accidents/사고분석-YYYY.xlsx   (예: 2023년 = 사고분석-2023.xlsx)
```

**규모:** 약 80,240건 (10년 누적, 사망+중상)

### 2.2. 기상 노출 데이터 (분모)

**기상청 지상(종관, ASOS) 시간자료**

| 속성 | 값 |
|---|---|
| **출처** | 공공데이터포털 API 조회 |
| **공공데이터포털 등재** | 데이터셋 ID `15057210` (기상청_지상(종관, ASOS) 시간자료 조회서비스) |
| **이용허락** | 출처표시(CC BY) |
| **저작자** | 기상청 |
| **데이터 형식** | JSON (API 응답) |
| **인증** | 공공데이터포털 활용신청 + 디코딩 인증키 필수 |

**수집 조건:**
- **지점**: 서울(지점번호 108) — 도시 주 관측소
- **관측항목**: 기온, 강수량, 신적설, 날씨(정성 기록)
- **시간해상도**: 시간별 (월간 API 호출)
- **기간**: 2014~2023 (120개월)
- **기준 시간**: 한국표준시(KST, UTC+9) 고정

**기상범주 분류 규칙:**
```
눈:   신적설(hr3Fhsc) > 0  또는  (강수량 > 0 & 기온 ≤ 0℃)
비:   강수량 ≥ 0.1mm  &  눈 조건 불만족
맑음: 강수 없음 (흐림 포함)
```

**저장 위치:**
```
data/raw/weather/asos_108_YYYYMM.json   (예: 2023-01 = asos_108_202301.json)
```

**규모:** 87,600시간 (10년 × 12월 × 일평균 ~730시간) — 노출시간 기준선

## 4. 재현 절차

### 4.1. 필수 구성 요소

1. **Python 3.8+** 및 필수 라이브러리 (`requirements.txt`)
2. **공공데이터포털 인증키** (`.env` 파일)
3. **TAAS 사고분석 엑셀 파일** (수동 다운로드)

### 4.2. 단계별 재현

#### Step 1: 환경 준비

```bash
# 저장소 클론
git clone <repository-url>
cd ujino-pbl

# Python 가상환경 생성
python -m venv .venv

# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# 의존성 설치
pip install -r requirements.txt
```

#### Step 2: 인증키 설정

```bash
# .env 파일 생성
cp .env.example .env

# .env 에서 다음 항목 입력:
# DATA_GO_KR_SERVICE_KEY=<공공데이터포털_디코딩_인증키>
```

**인증키 발급 방법:**
1. https://www.data.go.kr 로그인
2. 마이페이지 → 활용신청 기관 목록 확인
3. 「기상청_지상(종관, ASOS) 시간자료 조회서비스」(15057210) 활용신청
4. 승인 후 인증키 복사

#### Step 3: 사고 데이터 수집 (수동)

1. TAAS GIS 접속: https://taas.koroad.or.kr/gis
2. 조건 설정:
   - 도시: 서울특별시
   - 심각도: 사망 + 중상
   - 연도: 2014~2023 (각각 다운로드)
3. 목록보기 → 엑셀 다운로드
4. 파일 저장: `data/raw/accidents/사고분석-YYYY.xlsx`

**다운로드 후 폴더 구조:**
```
data/raw/accidents/
├── 사고분석-2014.xlsx
├── 사고분석-2015.xlsx
├── ...
└── 사고분석-2023.xlsx
```

#### Step 4: 기상 데이터 수집 (자동)

```bash
# ASOS 시간자료 수집 및 저장
python -m src.collect.fetch_weather
# → data/raw/weather/asos_108_YYYYMM.json 생성
```

#### Step 5: 분석 및 대시보드 생성

```bash
# 데이터 전처리 → 상대위험 산출 → 대시보드 생성
python -m src.analysis.pipeline
# → outputs/dashboard.html 생성
# → data/processed/zone_weather_risk.csv 생성
```

#### Step 6: 대시보드 확인

**로컬 실행:**
```bash
python -m src.serve
# → http://localhost:8000 에서 대시보드 접속
```

**또는 Docker:**
```bash
docker compose up --build
# → http://localhost:8000 에서 접속
# 중지: Ctrl+C 또는 docker compose down
```

## 5. 데이터 명세

### 5.1. 최종 분석 테이블: `zone_weather_risk.csv`

| 컬럼 | 타입 | 설명 |
|---|---|---|
| `zone_id` | int | 자치구 ID (예: 1=종로구, ..., 25=강서구) |
| `zone_name` | str | 자치구명 (예: "중구") |
| `weather_category` | str | 기상범주: "맑음", "비", "눈", "기타" |
| `accident_count` | int | 해당 자치구×기상의 사고건수 |
| `exposure_hours` | float | 해당 기상이 지속된 시간수 (ASOS 108 기준) |
| `relative_risk` | float | 상대위험(RR) = 사고율 ÷ 맑음기준 사고율 |
| `ci_low` | float | 신뢰구간 하한 (95%) |
| `ci_high` | float | 신뢰구간 상한 (95%) |
| `sample_n` | int | 사고건수(표본수) |

**예시:**
```
zone_id,zone_name,weather_category,accident_count,exposure_hours,relative_risk,ci_low,ci_high,sample_n
1,종로구,맑음,150,60480,1.0,0.85,1.18,150
1,종로구,비,85,12800,2.31,1.78,2.98,85
1,종로구,눈,22,240,3.58,2.12,5.89,22
1,종로구,기타,5,2000,,,,5
```

## 6. 한계 및 주의사항

### 6.1. 공간 해상도 제약
- 사고 데이터에 위경도 미포함 → 분석 단위 = 자치구(시군구)
- 다발지역 폴리곤 레벨 분석 불가능
- 자치구 내부의 지역별 위험 편차를 포착하지 못함

### 6.2. 기상 분류 이원화
- **사고 기상**: 경찰 정성 기록(TAAS) — 넓은 정의 (예: 눈은 강설부터 노면 결빙까지)
- **노출 기상**: ASOS 정량 관측 — 좁은 정의 (예: 신적설 > 0)
- **결과**: 눈 상대위험이 상향 편향될 수 있음 (분모 과소집계)

### 6.3. 노출편향 (Traffic Volume Bias)

> **문제**: 통행량이 보정되지 않음. 비나 눈 날씨에는 도로 통행량 자체가 감소하므로, 표면상 상대위험이 증가한 것으로 보여도 **실제는 통행량 감소에 의한 착시**일 수 있음.
>
> **현재 대응**: 노출시간으로 정규화하여 부분적으로 완화하나, 완전한 보정은 **미구현**.
>
> **향후과제**: 서울시 도로 교통량 데이터(시간대별·기상별)를 추가 입수하여 민감도 분석 실시. 예: "기상별 통행량 정규화 후 상대위험 재산출" → 위험이 얼마나 감소하는지 확인.

### 6.4. 소표본 경고
- 눈 사고: 자치구별 표본 매우 적음 (구별 최소 4건대)
- 자치구별 사고건수 < 10 또는 신뢰구간 과대 셀은 지도에서 경고 스타일(반투명) 표시
- 점추정(RR)이 아니라 신뢰구간과 함께 해석 필수

### 6.5. 발생시각 부재
- TAAS 데이터에 발생 시각(시 0~23)이 미포함
- 사고를 발생 일자 기준으로만 분류 가능 (불리한 점)
- 초기 설계의 "시간대별 기상 매칭"은 실제 구현 불가능

## 7. 검증 및 QA

### 7.1. 데이터 무결성 검증

```bash
# 자동 검증(파이프라인 내 포함):
# 1. TAAS 엑셀 컬럼 존재 확인
# 2. ASOS JSON 날짜 범위 확인 (2014-01-01 ~ 2023-12-31)
# 3. 자치구×기상 셀별 사고건수 ≥ 0 확인
# 4. 노출시간 > 0 확인
# 5. 상대위험 CI 계산 정상 여부 확인
```

### 7.2. 수치 재현 방법

분석을 재현하려면:

1. 위 Step 1~5를 순차 실행
2. `data/processed/zone_weather_risk.csv` 생성 확인
3. 주요 지표 비교:
   - 총 사고건수: 약 80,240건
   - 사고 데이터 기간: 2014-01-01 ~ 2023-12-31
   - ASOS 노출시간: 약 87,600시간 (10년)
   - 자치구 수: 25개
   - 기상범주: 4개 (맑음, 비, 눈, 기타)
   - 기대 행 수(비어있지 않은 셀): 25×4 = 100개 (미만 가능)
