| 다발지역 | 보행자 교통사고 다발지역 (data.go.kr 15105289, OpenAPI). 위경도+폴리곤+사고유형구분. 선정=반경100m·최근3년·7건↑ |
| 분석 기간 | **최대치 ~10년(예 2014~2023)**. 표본 극대화. 폴리곤 '최근 3년' 기준 불일치는 한계로 명시 |
| 기상 | 기상청 ASOS 시간자료(서울 108) 주 관측소 + 서울 AWS 다지점 보조(기온·강수). **눈(적설)은 ASOS 전용** |

## 분석 정의
| 항목 | 결정 |
|---|---|
| 지표 | 노출보정 **시간층화** 상대위험 (공간 gradient 아님 — 한 구역 내 기상범주 간 비교) |
| 기준선 | **맑음 대비** RR = (사고/노출시간)ᵇⁱ/ᵉ ÷ (사고/노출시간)ᵐᵃˡᵍᵘᵐ. "비/눈이면 맑을 때보다 N배" |
| 기상 범주 | 눈: 신적설>0 or (강수>0 & 기온≤0) / 비: 강수≥0.1mm / 맑음: 그 외 / 데이터없음: 결측(±1h tolerance 실패). 눈>비 우선. 분자·분모 동일 규칙 |
| 색상 구간 | 분위수(quantile) 5단계 choropleth. 소표본(n≤1) 셀은 빗금/투명 |
| `데이터없음` | 상대위험 계산 제외 + 지도 회색, 결측 비율 문서 명시 |
| 신뢰구간 | Poisson exact / Byar 근사. n=0~1 셀 degenerate 처리 |

## 개발/저장소
| 항목 | 결정 |
|---|---|
| DB 환경 | **Docker Compose** (`postgis/postgis` 이미지). `docker compose up` 재현 |
| 분석 스택 | Python (pandas, geopandas — `sjoin_nearest`, `merge_asof`), 시간축 KST 고정 |
| 서빙 | PostGIS 평문 테이블 → 카테고리별 정적 GeoJSON → Leaflet 필터 토글 |
| 라이선스 | 코드 **MIT**. 데이터는 저장소 미포함 + 출처표시(공공데이터 이용범위 준수) |
| 재현정보 | 데이터셋 ID·수집일·요청 파라미터를 문서에 기록 |
