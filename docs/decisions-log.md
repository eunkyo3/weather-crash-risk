# 결정 로그 (Decisions Log)

deep-interview + 합의 계획 + grill 세션에서 확정한 프로젝트 결정사항. (2026-07-09)

## 운영 제약
| 항목 | 결정 |
|---|---|
| 인원·기간 | 혼자, 약 1개월, AI 에이전트 도구 활용 |
| 진행 전략 | **수직 슬라이스 우선**(끝까지 동작하는 얇은 완성본) → 시간 남으면 확장 |
| 제출 산출물 | 4종: **동작 데모(녹화 백업)** + 발표 슬라이드 + 기획 보고서 + GitHub 저장소 |

## 데이터
| 항목 | 결정 |
|---|---|
| 대상 도시 | **서울특별시** (사망사고 최다 표본·ASOS 108·다발지역 밀집). Phase 0 미달 시 부산 대체 |
| 분석 유형 | **보행자(차대사람) 우선**, 파이프라인은 핫스팟유형 **파라미터화**(설정만 바꿔 전체로 폴백) |
| 사고 데이터 | 도로교통공단_사망 교통사고 정보 (data.go.kr 15070340, 연도별 CSV). **발생시간=시(0~23) 확인** → 시간대 기상매칭 성립. 사고유형=차대사람 필터, 위경도 개별 제공 |
| 다발지역 | 보행자 교통사고 다발지역 (data.go.kr 15105289, OpenAPI). 위경도+폴리곤+사고유형구분. 선정=반경100m·최근3년·7건↑ |
| 분석 기간 | **최대치 ~10년(예 2014~2023)**. 표본 극대화. 폴리곤 '최근 3년' 기준 불일치는 한계로 명시 |
| 기상 | 기상청 ASOS 시간자료(서울 108) 주 관측소 + 서울 AWS 다지점 보조(기온·강수). **눈(적설)은 ASOS 전용** |

## 분석 정의
| 항목 | 결정 |
|---|---|
| 지표 | 노출보정 **시간층화** 상대위험 (공간 gradient 아님 — 한 구역 내 기상범주 간 비교) |
| 기준선 | **맑음 대비** RR = (사고/노출시간)ᵇⁱ/ᵉ ÷ (사고/노출시간)ᵐᵃˡᵍᵘᵐ. "비/눈이면 맑을 때보다 N배" |
| 기상 범주 | 눈: 신적설>0 or (강수>0 & 기온≤0) / 비: 강수≥0.1mm / 맑음: 그 외 / 데이터없음: 결측(±1h tolerance 실패). 눈>비 우선. 분자·분모 동일 규칙 |
| 색상 구간 | 분위수(quantile) 5단계 choropleth. 소표본(n≤1) 셀은 빗금/투명 |
| `데이터없음` | 상대위험 계산 제외 + 지도 회색, 결측 비율 문서 명시 |
| 신뢰구간 | Poisson exact / Byar 근사. n=0~1 셀 degenerate 처리 |

## 개발/저장소
| 항목 | 결정 |
|---|---|
| DB 환경 | **Docker Compose** (`postgis/postgis` 이미지). `docker compose up` 재현 |
| 분석 스택 | Python (pandas, geopandas — `sjoin_nearest`, `merge_asof`), 시간축 KST 고정 |

| 재현정보 | 데이터셋 ID·수집일·요청 파라미터를 문서에 기록 |

## 데이터 소스 변경 (2026-07-14 실측 반영)
- **개별 사망사고 CSV (data.go.kr 15070340) 파기됨** — 페이지 자체가 열리지 않음, 재배포 중단. 집계 통계본(15070282/297 등)은 기상 분해가 없어 대체 불가.
- 대체 소스 = **TAAS GIS "사고분석 → 지역별" 엑셀** (`taas.koroad.or.kr/gis`, 조건검색→목록보기→엑셀). **좌표·발생시각 없음, 시군구 + 기상상태까지** 제공. 연도별 전량이 한 파일로 받아짐(구별 분할 불필요).
- **확정 변경 사항**:
  - 분석단위: 다발지역 폴리곤 → **자치구 25개** (좌표 부재로 강제 — 플랜 Phase0 게이트의 시군구 승격과 일치). 다발지역은 선택적 오버레이로 강등.
  - 기상 분자: ASOS 시간매칭 불필요 → 사고 데이터에 기록된 **경찰기록 기상상태** 직접 사용. ASOS는 **노출시간(분모) 전용**.
  - 심각도: **사망 + 중상** 확정. (사망만은 눈 10년 14건→구별 불가. 사망+중상이면 눈 연 21건·10년 ~200건으로 구별 지도 성립.) 지표를 **"심각(사망·중상)사고 위험"** 으로 재정의.
  - 기상범주: **맑음(맑음+흐림 비강수 통합) / 비 / 눈 / 기타(안개·결측=상대위험 제외)**. 눈은 소표본 경고 스타일.
  - 한계 추가: 사고 기상분류(경찰 정성기록)와 노출 분류(ASOS 정량관측)가 다른 출처 → 문서 명시.
- 데이터: `data/raw/accidents/{사망|사망중상|전체}/사고분석-YYYY.xlsx`. 로더: `src/analysis/accidents.py`. 확보 예정 = 사망+중상 2014~2023.
