# 분석 방법론 (Methodology)

> 서울 자치구별 심각(사망·중상) 교통사고의 **기상조건별 시간층화 상대위험** 산출 방법. 데이터 가용성 실측에 따라 확정된 최종 설계다. 배경/변경 이력은 [`decisions-log.md`](decisions-log.md) 참조.

## 1. 문제 정의

"같은 자치구 안에서, **비/눈일 때 심각 교통사고 위험이 맑을 때보다 몇 배 높은가**"를 노출시간으로 보정해 산출하고, 기상 필터로 자치구 위험 분포 변화를 보여준다.

> 이 지표는 구역 간 절대 비교(공간 gradient)가 **아니다**. 서울 도심 관측소가 소수라 구역 간 기상이 사실상 동일하므로, 정당한 해석은 **한 구역 내부의 기상범주 간 상대위험(시간층화)** 뿐이다.

## 2. 데이터

| 역할 | 데이터 | 단위/기간 |
|---|---|---|
| 분자(사고) | 도로교통공단 TAAS 사고분석(사망+중상) | 자치구별 개별건, 2007~2025 (19년) |
| 분모(노출) | 기상청 ASOS 서울(108) 시간자료 | 시간별, 2007~2025 (228개월, 166,559h 실측) |
| 지도 | 서울 자치구 경계 GeoJSON | 25개 구 |

사고 개별 데이터에 위경도·발생시각이 없어(자치구·기상상태까지 제공) **분석 단위는 자치구 25개**, 사고의 기상분류는 **경찰 기록 기상상태**를 사용한다.

## 3. 기상범주 분류 규칙

**분자(사고)** — TAAS 기상상태 라벨을 매핑:
- 맑음 ← `맑음`, `흐림` (비강수)
- 비 ← `비`
- 눈 ← `눈`
- 기타 ← `안개`, 결측 등 (상대위험 계산 제외)

**분모(노출)** — ASOS 시간자료를 규칙으로 분류(사고 라벨과 대칭):
- 눈: 신적설(hr3Fhsc) > 0 또는 (강수량 > 0 & 기온 ≤ 0℃)
- 비: 강수량 ≥ 0.1mm & 눈 아님
- 맑음: 그 외(강수 없음, 흐림 포함)

> ⚠️ 분자는 경찰 정성 기록, 분모는 ASOS 정량 관측 → **분류 기준이 완전히 동일하지 않음**(한계). 두 출처를 각각 맑음/비/눈 3범주로 정렬해 최대한 대칭화했다.

## 4. 상대위험(RR) 산출

각 자치구 `g`, 기상범주 `c`에 대해:

```
사고율(g, c) = 사고건수(g, c) / 노출시간(c)        # 노출은 서울 전역 공통(ASOS 108)
상대위험 RR(g, c) = 사고율(g, c) / 사고율(g, 맑음)   # 맑음 기준선 = 1.0
```

- 노출시간은 도심 관측소 특성상 구역 간 공통값 → 구역 내부 비교(시간층화)로 한정된다.
- **신뢰구간**: 두 포아송률의 비. 각 카운트에 **Byar 근사**(포아송 exact 구간의 닫힌형
  세제곱근 근사)로 비대칭 구간을 구한 뒤, 로그척도에서 **MOVER**(Method of Variance
  Estimates Recovery; Zou & Donner 2008)로 rate ratio 구간으로 결합한다.
  - 단순 Katz 로그근사 `ln(RR) ± 1.96·√(1/n_c + 1/n_맑음)` 는 정규 대칭 가정이라 눈처럼
    카운트가 작은 셀(구별 n≈4~34)에서 구간을 **과신(너무 좁게)** 한다. Byar는 소표본에서
    오른쪽으로 길어져 이를 보정하고, 대표본에서는 Katz 식으로 수렴한다.
  - scipy 없이 `math` 만으로 계산되며 모든 셀에 같은 방법을 일관 적용한다.
  - 구현: `src/analysis/risk.py` (`_byar_poisson_ci`, `_rate_ratio_ci`).
- **소표본·불안정 판정**: **사고건수 < 10** (`MIN_STABLE_N`) 또는 **CI 상한/하한 비 > 3**
  (`MAX_CI_RATIO`) 인 셀을 불안정으로 표시한다 — 지도에서 반투명·점선 경고 스타일.
  분자나 기준선이 0인 셀은 CI를 degenerate 처리한다.
- **다중비교**: 25구 × 2범주 = 50회 비교이므로, `pipeline.py` 가 Benjamini-Hochberg(FDR)
  보정 후 유의한 구 수를 **참고용으로 함께 출력**한다. 헤드라인 수치를 대체하지는 않는다.

## 5. 산출물

- `data/processed/zone_weather_risk.csv` — 구×기상 상대위험 테이블(건수·노출·RR·CI·표본n).
- `outputs/dashboard.html` — folium 자치구 choropleth, 맑음/비/눈 레이어 토글, 구 클릭 팝업(건수·n·RR·CI).
  - 색상 구간은 **레이어별 분위수 5단계**(결정로그 기준). 고정 절대구간을 쓰면 RR이 좁게
    분포한 레이어(비: 1.00~1.39)가 2색으로 뭉개져 무정보가 되기 때문이다. RR=1.0은
    "맑음 대비 상승/감소"의 의미 경계라 **그 레이어 분포 안에 있으면** 구간 경계로 포함한다.
    분포가 기준선 한쪽에만 몰린 레이어(현 데이터의 비 레이어는 전 구가 RR≥1.00)에서는
    빈 구간을 만들지 않고 범례가 어느 쪽인지를 문장으로 밝힌다 — "전 구 RR≥1.00(모두 위험)"
    또는 "전 구 RR<1.00(모두 안전)". **색도 값 기준으로 정해지므로**, 전 구가 기준선 미만인
    레이어에서 위로 열린 최상단 구간까지 한색으로 칠해진다(경계만 보고 난색을 칠하면
    안전한 구를 위험색으로 표시하게 된다). 1.0 미만은 한색,
    이상은 난색으로 칠해 방향성을 유지한다. 범례는 레이어마다 실제 경계값과 소표본
    구 수를 함께 표시하며 레이어 전환 시 같이 바뀐다.
  - 외부 CDN 없이 열리도록 Leaflet 자산을 HTML에 인라인한다(`assets/vendor/`). 오프라인에서는
    배경 지도 타일만 비고 폴리곤·라벨·범례는 정상 표시된다 — 발표장 네트워크 장애 대비.

## 7. 한계

1. **공간 gradient 아님** — 구역 간 절대 비교 불가, 구역 내부 시간층화만.
2. **기상 출처 이원화 → 눈 RR 상향편향 주의(정량)** — 사고의 기상은 경찰 정성 라벨, 노출은 ASOS 정량 관측이라 "눈"의 정의가 다르다. 실측상 ASOS 눈 노출은 19년간 **477시간**(전체의 0.29%)에 불과한데(사고 건수는 재수집 후 확정), 경찰 "눈" 라벨은 강설 후 노면이 눈·빙판인 시간까지 폭넓게 포착하는 반면 ASOS "눈"(신적설>0 등)은 좁게 잡혀 **분모가 체계적으로 과소집계 → 눈 RR이 상향 편향**될 수 있다. 또한 보고된 CI는 **카운트 불확실성만** 반영하며 분류 오분류 불확실성은 포함하지 않으므로(실제 불확실성은 더 큼), 눈 RR은 "정밀한 추정"이 아니라 "정성적 경향"으로 해석해야 한다.
3. **눈 소표본** — 눈 사고·노출 모두 희소(구별 눈 사고 최소 4건대). 사고건수<10 또는 CI 과대 셀은 대시보드에서 소표본·불안정 경고 스타일로 표기.
4. **노출편향** — 통행량 미보정(비/눈에 통행 자체가 줄면 위험 과대/과소 가능), 노출시간 정규화로 부분 완화.
5. **자치구 해상도** — 좌표 부재로 구 이하(다발지점) 해상도 불가.
6. **노출 결측이 맑음에 흡수됨** — ASOS는 "강수 없음"과 "관측 결측"을 모두 빈 값으로 보내
   구분이 불가능하다. 따라서 결측 시간은 맑음 노출에 포함되며, 이는 기준선 분모를
   과대추정해 **모든 RR을 상향**시키는 방향의 편향이다. 다만 관측 커버리지가 실측 ~100%
   (2007~2025 = 6,940일 × 24h = 기대 166,560h, 실측 관측 166,559h → 100.00%)라 실질 영향은
   미미하고, 행 단위 누락은 `weather_coverage()` 가 감시한다.
