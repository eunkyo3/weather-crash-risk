# 분석 방법론 (Methodology)

> 서울 자치구별 심각(사망·중상) 교통사고의 **기상조건별 시간층화 상대위험** 산출 방법. 데이터 가용성 실측에 따라 확정된 최종 설계다. 배경/변경 이력은 [`decisions-log.md`](decisions-log.md) 참조.

## 1. 문제 정의

"같은 자치구 안에서, **비/눈일 때 심각 교통사고 위험이 맑을 때보다 몇 배 높은가**"를 노출시간으로 보정해 산출하고, 기상 필터로 자치구 위험 분포 변화를 보여준다.

> 이 지표는 구역 간 절대 비교(공간 gradient)가 **아니다**. 서울 도심 관측소가 소수라 구역 간 기상이 사실상 동일하므로, 정당한 해석은 **한 구역 내부의 기상범주 간 상대위험(시간층화)** 뿐이다.

## 2. 데이터

| 역할 | 데이터 | 단위/기간 |
|---|---|---|
| 분자(사고) | 도로교통공단 TAAS 사고분석(사망+중상) | 자치구별 개별건, 2014~2023 (~80,000건) |
| 분모(노출) | 기상청 ASOS 서울(108) 시간자료 | 시간별, 2014~2023 |
| 지도 | 서울 자치구 경계 GeoJSON | 25개 구 |

사고 개별 데이터에 위경도·발생시각이 없어(자치구·기상상태까지 제공) **분석 단위는 자치구 25개**, 사고의 기상분류는 **경찰 기록 기상상태**를 사용한다.

## 3. 기상범주 분류 규칙

**분자(사고)** — TAAS 기상상태 라벨을 매핑:
- 맑음 ← `맑음`, `흐림` (비강수)
- 비 ← `비`
- 눈 ← `눈`
- 기타 ← `안개`, 결측 등 (상대위험 계산 제외)

**분모(노출)** — ASOS 시간자료를 규칙으로 분류(사고 라벨과 대칭):
- 눈: 신적설(hr3Fhsc) > 0 또는 (강수량 > 0 & 기온 ≤ 0℃)
- 비: 강수량 ≥ 0.1mm & 눈 아님
- 맑음: 그 외(강수 없음, 흐림 포함)

> ⚠️ 분자는 경찰 정성 기록, 분모는 ASOS 정량 관측 → **분류 기준이 완전히 동일하지 않음**(한계). 두 출처를 각각 맑음/비/눈 3범주로 정렬해 최대한 대칭화했다.

## 4. 상대위험(RR) 산출

각 자치구 `g`, 기상범주 `c`에 대해:

```
사고율(g, c) = 사고건수(g, c) / 노출시간(c)        # 노출은 서울 전역 공통(ASOS 108)
상대위험 RR(g, c) = 사고율(g, c) / 사고율(g, 맑음)   # 맑음 기준선 = 1.0
```

- 노출시간은 도심 관측소 특성상 구역 간 공통값 → 구역 내부 비교(시간층화)로 한정된다.
- **신뢰구간**: 두 포아송률의 비 → Katz 로그근사
  `ln(RR) ± 1.96 · √(1/n_c + 1/n_맑음)`
- **소표본**: n ≤ 1 셀은 CI degenerate 처리 + 지도에서 경고 스타일(반투명·점선).

## 7. 한계

1. **공간 gradient 아님** — 구역 간 절대 비교 불가, 구역 내부 시간층화만.
2. **기상 출처 이원화 → 눈 RR 상향편향 주의(정량)** — 사고의 기상은 경찰 정성 라벨, 노출은 ASOS 정량 관측이라 "눈"의 정의가 다르다. 실측상 **눈 사고 325건 vs ASOS 눈 노출 194시간**인데, 경찰 "눈" 라벨은 강설 후 노면이 눈·빙판인 시간까지 폭넓게 포착하는 반면 ASOS "눈"(신적설>0 등)은 좁게 잡혀 **분모가 체계적으로 과소집계 → 눈 RR이 상향 편향**될 수 있다. 또한 보고된 CI는 **카운트 불확실성만** 반영하며 분류 오분류 불확실성은 포함하지 않으므로(실제 불확실성은 더 큼), 눈 RR은 "정밀한 추정"이 아니라 "정성적 경향"으로 해석해야 한다.
3. **눈 소표본** — 눈 사고·노출 모두 희소(구별 눈 사고 최소 4건대). 사고건수<10 또는 CI 과대 셀은 대시보드에서 소표본·불안정 경고 스타일로 표기.
4. **노출편향** — 통행량 미보정(비/눈에 통행 자체가 줄면 위험 과대/과소 가능), 노출시간 정규화로 부분 완화.
5. **자치구 해상도** — 좌표 부재로 구 이하(다발지점) 해상도 불가.
